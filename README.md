## Overview
This repository contains FDTD simulations of core silicon photonics devices using [MEEP](https://meep.readthedocs.io/en/latest/), an open-source electromagnetic simulation package developed at MIT.

These simulations were built to bridge my background in **electro-optic materials (ferroelectric nematic liquid crystals)** with silicon photonics device engineering — specifically optical modulators and photonic integrated circuits.

---

## Why Silicon Photonics?
My PhD research focuses on electric field-induced electro-optic responses in ferroelectric nematic liquid crystals — achieving **300x tunability** of optical switching speed (0.54 ms to 164 ms) via molecular substituent engineering. This work directly connects to electro-optic modulator design in silicon photonics platforms.
